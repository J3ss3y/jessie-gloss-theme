# Jessie-Gloss (Nightfall-Gloss Edition)

A custom, dark, and semi-transparent GTK3 and Marco theme designed for the MATE Desktop. Built with a focus on clean aesthetics, crisp contrast, and a deep purple twilight look.

## Features
- **Dark Purple Aesthetics:** A sleek, moody balance tailored for dark desktop setups.
- **Translucency & Gloss:** Smooth, semi-transparent menus and panel elements.
- **High Contrast:** Clear visual feedback on menu item hover states.

## Installation
1. Download the release archive (`Jessie-Gloss-Theme.tar.gz`).
2. Extract and place the folder into `/usr/share/themes/` (or locally in `~/.themes/`):

   ```bash
   sudo tar -xzvf Jessie-Gloss-Theme.tar.gz -C /usr/share/themes/
   ```

3. Open **MATE Appearance** settings and select **Jessie-Gloss**, or activate it via the terminal:

   ```bash
   gsettings set org.mate.interface gtk-theme 'Jessie-Gloss'
   ```
